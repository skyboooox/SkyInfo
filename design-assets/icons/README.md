# 图形图标库

90个SVG：60个Tabler、30个原创。统一24×24网格、2 px描边、单色currentColor，深浅色由主题控制。

图标按图形本身命名和分类，例如“电池与叶片”“仪表盘”“漏斗”“座椅与气流”，不使用电池健康、转速、滤波温度等数据条目名称。图标分类与车辆数据/实体分类独立；组件或控制功能推荐使用哪幅图形，记录在单独映射中，不改变图标名称。

Tabler来自[官方仓库](https://github.com/tabler/tabler-icons)，沿用版本3.49.0及固定提交`a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d`，授权见[MIT文本](LICENSE-tabler.txt)。只移除元数据注释，几何与描边不变；缺少同风格图形的座椅、玻璃、后视镜、悬架等由项目补画。来源、版本、哈希及全部映射见[manifest.json](manifest.json)。

## 使用与搜索

分类与选择器使用连续列表，名称按图形显示，可按中文图形名或稳定英文ID搜索。实体名称可用于推荐匹配，但不覆盖图标显示名。未知实体建议六边形问号，并允许用户替换；不为每个实体、座位或档位重复生成图标。
