# SkyInfo 启动器图标

黑底、白色几何信息符号与右上黄色方块，基于用户提供的参考在 Figma Desktop Bridge 中重绘为可编辑矢量。正式源为 `skyinfo-launcher.svg`，对应传统 PNG、自适应前景与单色资源；文件哈希见 [manifest](manifest.json)。

Android 使用 `mipmap/ic_launcher`，按系统版本选择传统、自适应和单色图标；前景适配安全圆，OEM 遮罩效果仍需实机核对。Figma 品牌节点与维护方式见[设计说明](../../docs/Figma设计.md)。历史生成图、参考截图与实验文件未随公共项目发布。
