# 验证与兼容性

## 支持边界

主要适配依据来自豹5闪充版 2026 款，Android 14、CANFD、固件 59.7.4.26080703.1。固件字符串是诊断信息，实际接入按 SDK 方法、协议、当前用户和权限判定，不以单一版本或固定用户阻断。无法据此承诺其他车型、选装设备或所有系统更新可用。

公共目录包含 91 个显示字段（含 1 个计算功率）和 173 个固定控制实体。目录存在、接口接受、软件反馈、物理效果分别判断。39 个控制有历史实测依据，134 个推测控制仍标记待验证；不因生成镜像或单元测试通过而提升验证等级。

## 已有验证摘要

0.8.2 迁移前本机 Flutter 90 项、Android 148 项通过，分析与资源检查通过。0.8.1 的独立实机验证覆盖首次网络 ADB RSA 授权、代表温度/低压电压读取、重启无需重复授权、错误端口恢复及本地稳定曲线。旧版本曾完成代表 HA 数据类型、统一设备归属及软件控制读回核对；旧链路不替代新链路验证。

当前标准／放大的视觉和行为测试覆盖实际逻辑视口、卡片等比缩放与保存恢复。历史回归覆盖密度、峰谷、稀疏段、真实断点、单位变化和查询快照。测试夹具仅保留匿名数值/间隔/分布，不提供个人捕获时间或原始数据路径。

迁移后的离线结果记录在[迁移记录](迁移说明.md)。CI 只连接本机模拟 adbd、MockWebServer 和临时 MQTT Broker，不连接车辆、个人 HA 或公网 Broker。

## 未测项

0.8.2 的实机启动引导与图标、内置网络 ADB 无线配对、冷开机及长期回调、全部车辆控制的物理效果、所有车型/固件兼容、跨 Android 系统的真触摸与休眠恢复均未完整验收。

原始接口调查、实车截图、完整采样与失败诊断保存在维护者本地，不随公共源码发布。本页是验证摘要，不能替代独立物理标定或原始证据。报告新问题请提供脱敏复现，不直接上传原件。
