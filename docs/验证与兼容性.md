# 验证与兼容性

## 运行条件

Android 10+、ARM64；车机需提供本机网络 ADB 或无线调试接口。APP 按实际 Android 用户、权限、SDK 方法与协议判断能力，固件字符串仅作诊断。

适配依据为豹5闪充版 2026 款，Android 14、CANFD、固件 `59.7.4.26080703.1`。其他车型、选装、固件及屏幕需单独验证。

目录含 91 个显示字段（含 1 个计算项）和 173 个控制实体。39 个控制有实测依据，134 个推测控制保留待验证标记。字段解释见[转换与单位](字段转换与单位.md)，控制参数见[实体目录](../app/assets/entities.json)。接口接受、软件读回和物理效果分别判断。
