# 验证与兼容性

## 运行范围

Android 10+、ARM64，需提供本机网络 ADB 或无线调试接口。参考设备为豹5闪充版2026款、Android 14/CANFD、固件 `59.7.4.26080703.1`；其他车型、选装和固件需单独验证。

目录含92个显示字段、173个控制实体：39个控制有实测依据，134个推测控制保留待验证标记。目录存在、接口接受、软件读回与物理效果分别判断；字段定义见[转换与单位](字段转换与单位.md)，参数见[实体目录](../app/assets/entities.json)。

## HA 迁移与重连证据

Alpha16在HA 2026.11.0中验证：主车机下17个子设备、173个控件（11个switch、140个select、1个number、21个button）。44个保留组件的注册标识、实体ID与用户配置保持；472个旧组件精确替换为129个新select，无关实体与设备注册信息保持。17组、173组件及474参数映射另通过HA组件schema和本地映射校验。

风量提供1–7档、温度17–33°C整数范围；观察到风量1档/2档有效反馈，主驾按摩模式按当前反馈保持不可用。8个车辆传感器启动后恢复有效读数并持续上报。

手动重连后命令会话Topic轮换，设备/控件数量及保留注册信息保持，可靠反馈和车辆上报恢复。有限只读观察确认状态消息非保留，静态控制状态在有限同步后停止全量重发。车辆动作执行及物理效果仍需独立验证；升级操作见[发现升级](HA控制.md#发现升级)。

## 分屏证据

参考车机观察到菜单、应用选择、首次兼容提示，以及地图左大/SkyInfo右小的`7/3`布局。Alpha9（构建号11）中，SkyInfo与Spotify的下列组合通过实际窗口边界和可见状态核对，测试时媒体暂停：

| 左侧 / 右侧 | 系统预设 | 实际布局 |
| --- | --- | --- |
| Spotify / SkyInfo | `7/3` | 左大、右小 |
| Spotify / SkyInfo | `3/7` | 左小、右大 |
| SkyInfo / Spotify | `7/3` | 左大、右小 |
| SkyInfo / Spotify | `3/7` | 左小、右大 |

同版本验证组合创建、保存、快捷启动、编辑取消保留原值及删除；高级Activity可见，指定MainActivity保存重开保留，关闭高级选择保存后恢复默认入口；WebViewActivity显示未向外部开放标注。启动页设为自定义分屏后进程冷启及组合持久化通过，普通后台返回保留原页，测试后启动页恢复信息；Alpha13另观察到覆盖安装后的信息页冷启。

Alpha13沿用相同原生分屏实现，性能测试未重测组合。系统预设不保证像素精确70%/30%；请求状态和方向读回不能替代实际布局。更多Activity与禁选、应用组合、重复启动、单区全屏/空容器起始状态及整机启动恢复仍待验收；机制见[启动与结果](自定义分屏.md#启动与结果)。

## 性能证据

Alpha11与Alpha13的停车短时对照：全屏1920×1080信息页、6格卡片、21个需求字段、历史保留开启、减少动画关闭，图表加载后暖机；诊断关闭，均为完整120秒窗口。CPU单核当量为应用UID CPU毫秒/120000毫秒，I/O取native Watchdog的Linux写入统计。

| 每120秒窗口均值 | Alpha11（2窗） | Alpha13（4窗） |
| --- | ---: | ---: |
| CPU单核当量 | 0.395 | 0.226 |
| 写入量 | 1.750MiB | 1.592MiB |
| fsync次数 | 4 | 2.5 |

本场景平均CPU低约43%、写入字节低约9%、fsync低37.5%。两组进程不同，历史随时间滑动、输入组成不同，窗口写入有波动，不保证其他页面或长期运行幅度。独立诊断中，历史查询每点壁钟约43.4→8.2微秒、事件平均样本条目21→2.2，真实更新时间与状态变化继续通知；壁钟不是CPU时间。

均值趋势图的渲染表现需独立验证；Flutter帧回调未证实绘制耗时改善，不能推算帧率。Linux写入量不能推断闪存磨损或功耗。长期I/O、堆内存、功耗与休眠恢复仍需独立验证；[Alpha诊断](构建与发布.md#alpha性能诊断)默认关闭，不作为上述关闭窗口的替代。
