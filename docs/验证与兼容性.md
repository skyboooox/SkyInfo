# 验证与兼容性

## 运行与适配范围

Android 10+、ARM64，需提供本机网络 ADB 或无线调试接口。参考设备为豹5闪充版2026款、Android 14/CANFD、固件 `59.7.4.26080703.1`；其他车型、选装和固件需单独验证。

目录包含92个显示字段和173个控制实体。其中39个控制有实测依据，134个推测控制保留待验证标记；目录存在、接口接受、软件读回和物理效果不是同一种验证结果。字段解释见[转换与单位](字段转换与单位.md)，参数见[实体目录](../app/assets/entities.json)。
