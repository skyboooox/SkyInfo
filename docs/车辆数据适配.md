# 车辆数据适配

车机提供 autoservice SDK，APP 运行时访问，不携带厂商 JAR/APK。网络 ADB 在本机启动桥接，身份继承 adbd；普通 APP 与桥接权限分别判断。范围见[兼容性](验证与兼容性.md)，解码见[转换与单位](字段转换与单位.md)。

`车辆适配结果.json` 维护字段 ID、观察到的订阅状态和读取质量，供目录生成使用。callback_observed 仅表示曾观察到回调；注册接受不代表持续回调，通用读取错误不一概归为权限拒绝。

需求并集共享初读、订阅与缓存。订阅优先，轮询仅对实际未订阅字段按配置降级；静态版本按连接/版本变化读取，无权限不忙循环。诊断读取不改变字段选择或车辆状态。

无效编码/范围错误保留 raw，不作为有效数值上报或绘图。订阅间隔、采集新鲜度和物理单位分别核对。

`location.gnss_altitude`使用APP当前用户的Android定位接口，独立于网络ADB和autoservice FID；精确定位授权后按需启用定位前台服务和被动订阅，停止需求时释放。后台冷启动受Android定位前台服务限制，恢复到前台后重试。高度定义和失效规则见[字段转换](字段转换与单位.md)。

## 原车主题

自动主题优先读取 `content://carsettings/global` 的 `time_wallpaper_mode`：2为白天、1为夜晚；3为自适应时读取 Android Global 的 `key_byd_night_mode`（2为浅色、1为深色）。未知值、无权限或接口缺失时回退 Android 主题。订阅更新并在返回前台时重新核对，独立于采集和网络 ADB。

参考固件的 Android 夜间模式不随原车手动选择同步，`sys_day_or_night` 和 `sys_screen_mode` 也不能作为手动浅深选择依据；不使用时间、背光或车灯状态猜测主题。手动 APP 主题优先级及视觉规范见[宿主设计](../DESIGN.md#字体图标与主题映射)。
