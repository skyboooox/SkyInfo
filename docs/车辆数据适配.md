# 车辆数据适配

接口以目标车机运行时提供的 autoservice SDK 为准；APP 不携带厂商 SDK JAR/APK。网络 ADB 在本机启动桥接，实际身份继承 adbd 授权；普通 APP 权限和桥接接口权限分开判断。

适配与未测范围见[验证与兼容性](验证与兼容性.md)。`车辆适配结果.json` 仅保留字段 ID、历史订阅注册状态和读取质量，供目录生成使用；没有原始数值、UID、地址或捕获时间。历史 callback_observed 只代表观察过回调，不保证当前固件支持。当前显示按[转换与单位](字段转换与单位.md)处理。

运行时按仪表盘、悬浮条、上报和控制反馈的字段并集注册，共享初读与缓存。订阅优先；降级轮询只针对实际未订阅字段且由用户配置。静态版本字段按连接/版本变化读取，不高频采集；无权限不忙循环。

无效编码与字段范围错误保留 raw，不作为有效数值上传或连入曲线。注册接受不等于观察到持续回调，通用读取错误不全部归为权限拒绝。只读诊断不会改变字段选择、车辆状态或其他 Android 用户的数据。
