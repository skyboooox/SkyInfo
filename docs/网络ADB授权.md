# 网络ADB授权

网络 ADB 启动应用内置的本机 app_process 桥接。桥接继承 adbd 实际身份，以当前 APP 用户及 SDK 权限接入。

## 连接

设置 → 高级 → 网络ADB → 连接设置。应用启动即检查连接，默认127.0.0.1:5555；可改为本机LAN地址和实际连接端口。传统TCP首次在系统提示中接受SkyInfo独立密钥。Android无线调试先输入配对端口和六位码，配对完成后用连接端口连接，两者不可混用。系统需已启用对应调试能力；APP不自动改变调试开关。

使用[LibADB Android 3.1.1](https://github.com/MuntashirAkon/libadb-android/tree/3.1.1)完成RSA认证、流和TLS配对；固定上游源码以独立Android库模块引入，仅补连接/配对/OPEN超时和提前响应的通知竞态，来源与补丁见[依赖说明](../app/android/third_party/libadb/README.md)。使用Apache-2.0授权版本及其依赖许可；应用不提供任意shell命令界面。

独立RSA密钥加密保存在本机，配置导入/导出不包含密钥或配对码，卸载后需重新授权。连接目标在启动前以当前网络接口地址校验，不对其他设备启动进程。ADB连接状态、桥接身份、SDK权限和悬浮权限独立呈现。未授权、端口不可达、需要配对与错误不能伪造为正常采集。

## 生命周期

APP每次启动默认开启采集和本机ADB检查；前台无组件时也执行连接检查。未授权弹出一次APP引导，确认进入连接设置处理系统RSA授权或无线配对；端口不可达单独提示连接设置，不反复自动弹窗。仅按已保存连接地址启动本机桥接；断开释放流与订阅，标记已有样本失效，以1—60秒退避恢复。停止运行关闭ADB，开机按已保存偏好恢复，不自动弹前台。连接配置改变关闭旧会话。控制请求没有断线队列，重连不重放；请求按固定执行计划与反馈规则处理。普通APP能读取的系统信息继续直接读取。

实现使用 [LibADB](../app/android/third_party/libadb/README.md)，验证范围见[兼容性](验证与兼容性.md)。
