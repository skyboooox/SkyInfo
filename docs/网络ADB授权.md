# 网络ADB授权

网络 ADB 启动应用内置的本机 app_process 桥接。桥接继承 adbd 实际身份，以当前 APP 用户及 SDK 权限接入。

## 连接

设置 → 高级 → 网络ADB → 连接设置。未处于授权暂停时，应用启动检查连接，默认127.0.0.1:5555；可改为本机LAN地址和实际连接端口。传统TCP首次在系统提示中接受SkyInfo独立密钥。Android无线调试先输入配对端口和六位码，配对完成后用连接端口连接，两者不可混用。调试开关按下述恢复规则处理。

使用[LibADB Android 3.1.1](https://github.com/MuntashirAkon/libadb-android/tree/3.1.1)完成RSA认证、流和TLS配对；固定上游源码以独立Android库模块引入，补充连接/配对/OPEN超时、提前响应通知竞态及RSA授权阶段回调，来源与补丁见[依赖说明](../app/android/third_party/libadb/README.md)。使用Apache-2.0授权版本及其依赖许可；应用不提供任意shell命令界面。

独立RSA密钥加密保存在本机，配置导入/导出不包含密钥或配对码，卸载后需重新授权。连接目标在启动前以当前网络接口地址校验，不对其他设备启动进程。ADB连接状态、桥接身份、SDK权限和悬浮权限独立呈现。未授权、端口不可达、需要配对与错误不能伪造为正常采集。

## 调试开关恢复

设置 → 高级 → 权限提供“自动开启系统ADB”开关，默认关闭，选择即时保存。开启后，在每次 APP 启动及本机 ADB 刚取得授权并建立可执行会话时，将以下系统设置置为开启：

```sh
settings put global adb_enabled 1
settings put global adb_wifi_enabled 1
```

打开开关时立即按当前权限尝试恢复；关闭只停止后续自动恢复，不关闭系统 ADB 或中断现有连接。启动阶段优先使用 APP 已具备的系统设置写入权限；权限不足时，连接成功后由本机 ADB 桥接执行。分别检查执行结果并读回设置，不将写入成功等同于 ADB 已连接。重复连接时已开启的设置不重复写入。

启用此项后，ADB 桥接尝试向当前 APP 用户授予 `android.permission.WRITE_SECURE_SETTINGS`，供后续启动直接恢复；不向其他用户授权，也不提供任意命令入口。授权或写入失败保留真实状态，说明弹窗显示恢复结果；关闭此项不撤销已取得的权限。

车机重启可能关闭 ADB；如果 APP 没有设置写入权限且 ADB 不可用，仍需通过车机系统启用调试后恢复连接。Android 原生无线调试需要先将车机连接到 Wi-Fi（可连接手机热点），并允许当前网络；切换或断开 Wi-Fi 后可能需重新开启或确认。车机自带 TCP 入口按实际能力处理，不将原生无线调试的网络要求套用到所有 TCP 连接。写入开关不代替网络授权、配对或连接端口配置，开关状态不代表 ADB 已连接。网络前提参见 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi-android-11+)。

圆圈“!”说明用三段简述恢复作用、Wi-Fi与首次授权、手动恢复与关闭行为，正文维护在语言资源 `auto_system_adb_message`。标题和关闭操作固定；查看说明不切换开关，文字放大或出现恢复结果时可滚动。

## 会话与恢复

启动恢复采集；未处于授权暂停时检查本机ADB，前台没有组件也执行检查。需要系统RSA确认或无线配对时持久保存“需要授权”状态，停止后续自动尝试。启动引导与高级权限状态行提供连接设置入口。

暂停跨后台恢复、配置保存/导入、服务及进程重启保留；进入设置或选择“稍后”不发起连接。连接设置的“保存并连接”只发起一次尝试，成功取得授权后解除暂停，恢复正常自动连接。普通端口不可达及未进入授权阶段的连接超时提示连接故障，按1—60秒退避恢复。

桥接仅使用已保存的本机地址。断开释放流与订阅，标记已有样本失效；停止运行关闭会话，连接配置改变关闭旧会话。开机按已保存偏好恢复，不自动打开前台。车辆控制没有断线队列，重连不重放；普通APP可读取的系统信息继续直接读取。

授权引导提供“授权连接”和“稍后”：前者进入连接设置，后者保留暂停。同一轮等待只提示一次，后台出现的提示在返回前台后展示；普通连接故障每次启动提示一次，显示实际地址及连接入口，已连接不弹。

实现使用 [LibADB](../app/android/third_party/libadb/README.md)，验证范围见[兼容性](验证与兼容性.md)。
