# SkyInfo架构与维护

当前采用Flutter主界面和Kotlin运行层；已进入实现，不再维护互相冲突的HTML/HA历史旧方案。功能要求见[需求](需求说明.md)，交付见[开发状态](开发状态.md)。

UI/UX使用[Fluorite Design](design/fluorite-design/DESIGN.md)，[宿主DESIGN](../DESIGN.md)仅维护车机差异；上游Web仅供参考，Flutter/Android保留各自正式实现。子模块初始化、升级及检查见[工具说明](../tools/README.md#fluorite-design)。

`models.dart`和`editors.dart`保留导出入口，真实实现已按模型和编辑器拆分。四页共享Shell，专题编辑和设置使用part文件，状态归属不复制。通用UI分别维护在industrial主题及buttons/selection/controls分件、layout响应式布局、design_dialog路由、navigation导航、attention反馈和confirmation确认中；历史偏好、字段行与工具栏独立，避免编辑器与四页复制相同操作合同。生成数据与原始证据允许较长文件，不机械拆散固定计划和资源字典。

## 采集与需求合并

仪表盘、悬浮条、逐条上报、已确认控制反馈及可见预览共同声明字段需求。实体ID`control.<action>`映射到已确认的反馈字段，推测实体不会批量声明推测读取。依赖展开共享输入，功率直接使用GB电流，不增加额外轮询。

普通APP与内置网络ADB启动的shell桥接能力分别记录，不能用shell成功代替普通UID权限。默认订阅；降级轮询只针对未订阅字段并由配置控制。回调合并更新共享样本，语义变化才触发传感器/实体上报。订阅与本地记录的采样频率不被图表抽取算法改变。

预览需求使用每个组件/弹窗独立租约，合并为一次原生需求。关闭某个弹窗只释放其自己的字段，嵌套预览不覆盖父页面。预览不保存配置，不自动上传，不建立历史，不写车辆。

## 实体控制

实体元数据与固定写入执行器分开：元数据决定名称、图标、分类、可选参数及反馈；执行器动态识别实际用户与权限，按SDK方法及适配协议判断兼容性，校验离散参数及真实反馈；完整固件只留诊断，不按固定用户/UID或P挡阻断。单参数动作按按钮呈现，不能根据min/max开放中间参数。

APP只有仪表盘已添加的实体能下发命令，编辑/预览禁用动作。请求期间去重，回执单独显示；共享反馈订阅更新状态，不能从请求值或accepted响应生成开关状态。数值状态与单位独立，避免重复°C。HA原生实体无需先添加APP组件。

## 历史与图表

全部查询读取本地SQLite，删除废弃HA历史解码路径。只有已配置字段持久化，保留观察覆盖时间、真实断点、来源及解释版本。开发期可舍弃旧配置、历史及旧格式，不要求增加迁移代码；现有读取转换路径不构成兼容承诺。车辆原始证据和其他HA设备不在清理范围。图表将主线与逐桶极值背景分开，按画布像素保留采样密度；真实空白、暂停和来源切换不连接。

## 通信

默认HA：HTTP用于发现和状态发布，WebSocket用于服务恢复及命令订阅。原生switch/select/number/button共用SkyInfo设备标识；每次在线会话生成独立控制Topic，QoS0、非保留，掉线不补放车辆动作。未知读回、65535、两侧温度不一致不伪装为有效状态。既有HA事件脚本仍作为兼容入口。

自定义MQTT在高级设置，复用Paho5/3.1.1、TLS、会话和有效期校验。HA允许配置HTTP/HTTPS域名与IP，优先HTTPS，HTTP提示一次；原生配置、REST、WebSocket共用HaEndpoint，Dart保存校验与Android网络策略保持一致。MQTT明确选择TLS/普通TCP，默认TLS。Keystore保存运行时凭据，不进入构建产物。详见[HA](HA控制.md)、[MQTT](MQTT控制.md)。

## 视觉与资源

复用Flutter动画、滚动、网格、对话框和flutter_svg；Android网络复用OkHttp/Paho，存储SQLite。共享主题、控件、交互和动效适配固定版Fluorite；宿主差异只在DESIGN维护，实际落地差异记开发状态。工业主题和极值图层保留必要定制，不为增加库数量替换已有稳定功能。

中文资源以`app/assets/i18n/zh_CN.json`为单一编辑源；Dart和Kotlin默认表由工具生成。资源键、实体ID与图标ID稳定，推荐映射独立于图形分类；生成顺序及校验见[工具说明](../tools/README.md)。新增语言先补资源、占位参数和长文本验证，再实现运行时语言选项；本次不宣称已支持外语。

## 验收边界

Docker静态分析、Flutter行为/视觉测试、Android单元测试和TLS MQTT模拟验证属于本机验证。安装、真实触摸、重启恢复、真实HA实体发现、网络恢复及物理控制属于实车/实服验收，分别记录。原有SDK记录不因本次重构重新计算为通过。

## HA实体来源与创建流程

新增HA来源适配器负责实体目录、能力、状态/属性和共享WebSocket会话；不把外部HA实体写入静态车辆SDK目录。以连接UUID、entity_id和state/属性键作为稳定绑定，原始状态与已解析样本分别保留。复用现有安全凭据与通信库，来源模型、缓存租约及本地历史共用接口，不复制每组件轮询器。

HA实体执行器按domain及实际服务能力调用明确目标，车辆执行器保持既有白名单。HA来源不自动反向上报，镜像车辆实体仍走原车辆控制链。接口依据和验收边界见[HA实体接入](HA实体接入.md)。

创建/编辑维护一份草稿，选择器带入当前选择并返回调用处；按数据数量、类型、能力约束样式与尺寸。主页三步创建、预设捷径、已保存编辑和悬浮模块配置共用选择模型，避免保留平行的旧入口。当前实现及实机验收边界见[开发状态](开发状态.md)。HA状态逻辑位于`ha_controller.dart`，原生来源与能力分别由`HaEntitySource.kt`和`HaEntityModel.kt`维护。
