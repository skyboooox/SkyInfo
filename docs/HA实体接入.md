# HA 实体接入

## 来源与连接

HA既是SkyInfo的上报目标，也是独立的数据和实体来源。复用连接页的HA地址和安全凭据；连接页提供实体接入状态及入口。接入开关、失败详情和重新连接放在连接设置。接入不依赖车辆上报或HA车辆远控开关，关闭上报仍可读取HA。

| 方向 | 用途 | 执行边界 |
| --- | --- | --- |
| 车辆 → SkyInfo → HA | 现有车辆传感器、控制发现及反馈 | 上报协议与固定计划 |
| HA → SkyInfo → 车辆 | HA控制SkyInfo车辆实体 | 鉴权、有效期、固定参数及接口兼容性 |
| SkyInfo → HA现有实体 | 读取、显示及调用HA实体功能 | HA连接用户权限、实体能力与明确目标；不调用车辆SDK |

HA中由SkyInfo上报的实体也可以被选中，但来源仍明确为HA；不按名称合并到本地车辆字段，不再次换算已经带单位的状态。HA镜像车辆实体的操作仍经HA→车辆执行链，不能绕过车辆限制。HA来源值默认不向HA或自定义MQTT上报，避免回环和重复实体注册。

## 实体与数据模型

实体包含连接标识、entity_id、名称、区域、设备、domain、状态、属性、单位、质量、时间及可用功能。稳定绑定采用连接UUID和实体ID；更换HA地址生成新连接UUID，原有绑定保留为离线来源，须重新选择新来源，不自动绑定另一服务器的同名实体；显示值另绑定state或具体属性键。车辆字段和HA实体使用不同来源命名空间，相同名称不能覆盖。属性与状态分别保存单位与类型；选择属性只是读取，不自动获得写权限。

HA状态协议中的字符串不一概作为文本，也不一概转换成数字。数值传感器及有数值契约的number/属性只接受有限数；开关、枚举、日期和文本保持相应语义，unknown/unavailable/缺失不得转换为0。实体状态与原始属性都保留，显示单位不改变服务参数。状态时间使用HA的last_updated/last_changed；属性首次观察的变动时间未知，后续仅在该属性实际变化时记录变动时间，其他属性变化不改写它。HA数值已解释，不应用车辆raw换算。

主界面允许车辆和HA混合列表、数值、状态、文本、历史及控制组件；同设备组合只包含用户逐条选定的实体。悬浮条可显示HA状态或标量属性，不含控制功能。HA实体没有物理单位时不放占位单位。

## 能力与控制

先根据domain、服务、supported_features及实体属性建立能力；缺少范围、选项或必要属性时隐藏相应功能。以下是产品覆盖范围，不能视为所有集成均支持。

| 实体类型 | 组件及可用功能 |
| --- | --- |
| sensor、binary_sensor及只读实体 | 数值/状态/文本/历史；无写入 |
| switch、input_boolean、light | 开关；light按实际能力提供亮度和色温，RGB/HS颜色编辑暂不提供 |
| number、input_number | 数值输入或加减，遵守实体min/max/step及单位 |
| select、input_select | 只显示实体提供的options |
| button、input_button、scene、script | 显式动作；脚本执行状态不冒充设备开关状态 |
| climate | 当前温度、目标温度、模式；仅提供支持的功能 |
| cover | 支持时提供开/关/停止/位置 |
| fan | 支持时提供开关、档位/百分比、预设 |
| lock | 显式锁定/解锁，解锁二次确认；需要密码的操作不保存明文密码 |
| media_player | 支持时提供播放/暂停、音量等实体功能 |
| vacuum | 支持时提供启动、暂停、停止、返回基座 |
| 未适配domain或功能 | 可展示有效状态/属性，控制只读，详情说明原因 |

控制只存在于已保存到仪表盘的实体组件及其详情。选择、预览、配置及布局编辑均不执行。功能区与打开详情的区域分开；发送期间防重复，离线禁止发送；按钮/场景等动作实体unknown不作离线阻断，按实际服务能力判断，无离线队列或自动重放。服务成功代表请求处理结果，状态需由HA后续反馈更新；动作没有目标状态时显示已发送，不伪造“已确认”。状态反馈仍不能证明物理效果。

## 订阅、历史与异常

接入初次获取实体状态和服务，后续复用单一WebSocket会话订阅状态事件；使用请求ID关联结果。仪表盘、悬浮条和可见预览共享缓存与需求租约，不按组件创建轮询器。区域/设备注册信息不可读时，按类型和未分配区域展示，不阻断状态读取。重连重新读取快照并恢复订阅，不补造断线样本。

历史全部本地，仅记录用户配置在仪表盘的数值状态/属性和受支持的状态历史；悬浮条或浏览预览不自动记录。关闭HA连接后已存历史仍可查询，但没有新HA样本；不调用HA历史补齐。记录来源、字段路径、类型、单位及会话边界，单位变化或断链不能直接连线。

未连接、鉴权失败、权限不足、实体被移除、属性缺失和不可用分别显示实际状态。保留用户已保存绑定，不自动改绑同名实体；最后有效值只能作为过期缓存展示，不能显示为实时。只读实体可在离线选择器中查看已有缓存；保存有效绑定不代表获得控制权限。
