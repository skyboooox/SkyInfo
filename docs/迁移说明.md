# 独立仓库迁移

SkyInfo 从个人 BYD 工作区迁移为独立 Git 仓库，公共历史以当前审阅后的源码开始，不包含旧工作区历史。

## 发布内容

Flutter/Android 源码、正式资源、固定车辆字段/控制计划、当前产品/设计/架构文档、匿名回归数据、测试视觉基线和离线 CI。Fluorite Design 保持原固定提交，以 submodule 引用；普通构建不需要相邻调查或 Web 验证台。

## 本地保留内容

个人签名与运行配置、实车截图和诊断、HA 观察记录、完整充电/行驶采样、旧检查点、Figma 原件备份、未采用的设计试验及旧目录完整内容由维护者保留，均不进入新公共 Git 历史。测试夹具保留回归所需值/间隔，去除原捕获路径和时间。

## 验证

迁移后的资源重新生成无差异，文档链接、设计 gitlink、GPL/第三方说明及公开文件检查通过。干净克隆 Flutter analyze 无问题、90 项测试通过；Android 148 项通过且无失败/错误/跳过，Debug ARM64 APK 构建成功。Gradle wrapper 9.1.0 的 JAR/ZIP 校验值核对后，另一份全新克隆通过了“分析后直接原生测试”的 148 项回归。Gitleaks 检查新仓库及设计依赖历史均未发现凭据；设计子模块采用与公开上游 API SHA 一致的本地缓存，GitHub Actions 云端结果仍待首次公开后核对。CI 采用固定 Docker 镜像，临时 MQTT 测试用独立 Docker 网络，支持 macOS 和 Linux。

## 发布状态

目标为 skyboooox/SkyInfo，GPL-3.0-only。当前仅本地准备，尚未创建远端、推送源码或发布 APK；首次公开必须经过维护者人工确认。BYD 工作区仅引用 SkyInfo gitlink，研究项目继续独立保留私有证据。

目录组织参考 [LocalSend](https://github.com/localsend/localsend) 的构建/贡献/版本说明及 [scrcpy](https://github.com/Genymobile/scrcpy) 的文档分工，按本项目实际内容取舍，未复制上游代码或文案。
