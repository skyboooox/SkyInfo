# 组件添加与数据选择

更新：2026-10-12。本页替代“先按展示样式/预设/实体分入口，再反复选数据”的旧操作逻辑。保留现有组件和预设能力，使用同一份草稿和选择器；0.6.0已实现，行为及浅深色验证见本轮QA（内部记录，未随公共源码发布）。

## 添加到仪表盘

信息页铅笔进入编辑模式，才出现添加组件。创建流程为：

1. **选择数据或实体**：统一车辆与Home Assistant来源，可选一项或多项；也可以使用预设预填。
2. **选择组件**：按数据数量、类型与实体能力推荐可用样式，单数值默认数值2×2；控制实体推荐实体卡，多项推荐连续实体列表。可浏览其他兼容样式，不兼容项说明缺少什么，不静默删数据。
3. **配置组件**：左侧持续预览，右侧通过内容、外观、实体功能页签配置，首次展示外观；历史仅在适用组件中出现。修改立即更新正式组件预览，保存后返回仪表盘编辑状态。

顶部显示同一套当前步骤与关闭；主操作固定在底部。新增追加组件并保留原有内容，新增后进入布局编辑、取消配置或浏览其他页面不丢失已保存组件。配置中的内容页可原路重新选择数据或组件，底部不重复设置更换入口。上一步保留数据、顺序和配置，取消不改变已保存组件；只有保存持久化。更换样式保留兼容配置，数据数量或类型不匹配时要求明确修改，不偷偷替换实体。实体控制预览不执行，真实数值缺失为“—”。

预设是捷径，不是另一套创建流程。选预设后得到可编辑的数据组合和样式，进入配置；不立即添加或开启历史/控制。现有12种只读样式、7种实体样式、11个预设保留，按适用条件筛选，不将各种小组件拼成数据列表。

## 统一选择器

“10 · 添加组件”的第一步与“14 · 选择数据”共用来源、搜索和列表逻辑。前者创建组件并可多选，后者按调用处单选/多选并确认返回原配置页；悬浮条选定数据后直接配置模块，不经过组件样式页。

| 区域 | 交互 |
| --- | --- |
| 来源 | 全部、车辆、Home Assistant；切换保留已有选择 |
| 搜索 | 名称、字段/实体ID、设备、区域；跨当前来源搜索，不受左侧分类限制 |
| 分类/筛选 | 车辆按现行数据分类；HA将区域、设备、类型分为独立连续列表，区域未分配、类型未知有明确入口；显示当前筛选并可清除，改变筛选保留已选 |
| 数据列表 | 连续整行，名称、实时值/状态与单位、必要的来源/可控状态，X复选框；复选框与名称区选择，右侧独立箭头只打开详情，不触发控制 |
| 实体详情 | 查看来源、entity_id、能力及状态/属性；具体属性作为独立显示值绑定 |
| 已选 | 查看跨来源结果，移除及拖动排序；数量准确，不因搜索隐藏已选项而取消选择 |
| 底栏 | 已选数量、取消/返回、选择组件或确认；未满足数量/类型要求时禁用并给出必要提示 |

主界面多选允许跨来源；同设备组合要求选定实体确属同一设备。未知类型只读，不出现假开关。长列表保留滚动位置，搜索清除返回原分类；分类高亮和滚动内容裁切在视口内，不遮挡固定标题、搜索及底栏。

HA行默认用friendly_name，重名时补充设备/区域或ID；技术ID集中在详情，搜索仍支持。显示状态或属性的选择可在实体详情完成，数值属性只有类型、单位与用途明确时才推荐数值样式，任意数组/对象不拼成数值。

## 配置与编辑

配置分为内容、外观、数据设置或实体功能三个页签，每次只展开一组，按类型提供3–4条连续参数；默认数值组件仍为标题、数值、单位。新建时先显示外观，切换页签保持同一草稿，左侧预览不中断。标题直接编辑，兼容尺寸使用纯网格图标就地选择，不显示“2×2”等文字，预览也用比例图形；内部固定格数规则保留。图标关闭或选择后显示对应预览；单位/精度只在适用类型出现。时间显示为不显示、更新时间、变动时间三选一，直接呈现，默认不显示。多项数据使用连续列表，逐行配置标签、图标、单位及顺序；不把单项设置做成散乱卡片。

单位选择不包含精度设置。自动单位沿用绑定字段；多数据组件逐字段设置，混合量纲不由统一单位覆盖。未知单位保留原值，显示精度不改变已确认换算规则。

历史仅对适用数据出现，读取已有本地记录；保存后的仪表盘需求才开始记录。没有历史时保留当前数值和真实空图，不借用其他实体曲线。控制功能按实体能力显示，无适用功能时隐藏实体功能页签；名称/状态打开详情，功能区独立操作；APP执行按原生能力及反馈判断，规则见[HA实体接入](HA实体接入.md)。

编辑已保存组件直接进入配置，重新选择数据回到同一选择器并带入当前选择，不重走全部步骤。删除仅在编辑器中，组件右上角只保留一个铅笔。删除前显示确认，说明对象与影响；取消/关闭/Esc/外部点击保留组件及草稿。确认只移除该组件及显示设置，已记录历史不因此自动清空。尺寸不兼容时不能保存；移动通过仪表盘长按拖动。

## 悬浮条模块

新增模块 → 选择一个车辆值、HA状态或标量属性 → 配置图标、数值/状态、单位及对齐 → 保存。无预设，不强制图标，无单位状态不占单位位。配置页上方全宽只预览实际悬浮条，下方连续参数行；不模拟车机状态栏。图标库按图形名称分8类，同一目录包含90个图形；分类定位不打开新的选择窗口。选择图标或单位后返回原调用处，保留整份草稿。HA模块与车辆模块可混排，整体位置和锁定穿透规则不变，任何预览或实际悬浮条均无控制入口。

## 连接与状态

HA未配置显示连接入口，回到选择器后保留草稿；鉴权失败、加载、空结果、实体不可用分别呈现，不用示例值填空。离线可显示已有缓存并标过期；HA控制禁用。连接页区分HA接入、车辆上报和车辆远控，关闭某一方向不自动关闭其他方向。浏览HA实体只访问目录，不改变车辆上报选择；上报勾选形成草稿，底部“保存上报选择”确认，无修改时禁用，“撤销修改”只恢复该草稿。

正式E原型展示固定向导、返回/保存路径、页签与控件状态；运行时草稿仍以APP交付合同为准，搜索、输入、拖动、订阅和命令不由原型执行。新增画板和预览来源见[Figma设计](Figma设计.md)。

## E正式版交付边界

E已推广到全部正式模块，包括四页、选择器、54个配置状态、悬浮模块、设置、历史、实体详情与导航。中性灰阶、矩形48px按钮、80px连续参数、分组页签、兼容纯图标尺寸和主题色开启控件统一；蓝/绿/玫红按需使用，普通入口与来源保持中性。

Figma展示固定路径；APP以同一份草稿处理动态筛选、跨来源已选数量、配置与真实缓存预览联动及减少动画，实际行为另作回归验证。原型中的尺寸/时间变体用于审阅控件状态，不代表实际调整了运行时网格。详情独立于选择，配置开关只决定显示功能，不执行服务。车辆与HA控制详情统一720×720px，当前状态与请求目标分开；等待时锁住该实体全部操作入口，关闭只退出详情，不撤销已发送命令。只读详情保留车辆字段、HA实体两个示例，其余入口不误连示例；APP按实际条目加载。见[Figma交付](Figma设计.md)。

创建底部为取消和“添加到仪表盘”，编辑底部为取消、删除和“保存修改”。内容页承担更换样式，编辑不显示新建步骤。按钮160–192px宽，不拉伸成整个底栏，不缺角；尺寸图形保留无障碍名称，格数仅作为布局模型。
