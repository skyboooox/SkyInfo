# SkyInfo需求说明

更新：2026-10-13。本文只维护当前产品要求；实现及验收见[开发状态](开发状态.md)，历史方案见归档（内部记录，未随公共源码发布）。后续用户明确要求覆盖旧方案。

开发期不要求兼容旧配置、历史或数据格式；结构调整可舍弃SkyInfo旧数据，以当前格式重新配置和验收。此要求不允许清理HA其他设备或篡改调查证据，完整备份/迁移不是本阶段的产品承诺。

## 目标与平台

显示车机隐藏或不便查看的信息，避免默认重复展示原车已容易看到的车速、SOC、挡位等。Flutter主界面，Android原生采集、悬浮窗、后台服务和通信；包名`app.skyinfo.vehicle`。优先Docker构建。

SkyInfo面向公开分发，不以单一测试用户、私有服务器、固定设备名称或完整固件版本作为产品配置前提。车辆兼容范围仍须依据接口适配与验证明确说明，不将面向所有用户分发等同于支持全部车型和功能。

车辆授权改为SkyInfo内置网络ADB，不依赖Shizuku安装、运行或授权。默认本机127.0.0.1:5555，可配置本机网络地址及端口；应用启动检查本机连接，首次由用户在系统中接受SkyInfo独立RSA密钥。支持传统TCP授权及无线调试配对，配对端口与连接端口分别输入，配对码只用于当次配对。开启网络ADB仍由车机系统提供，APP不擅自打开系统调试开关。应用每次启动默认开启采集（含此前中断或停止），保留用户已保存的显示档位；启动即检查本机网络ADB，未授权时提供授权提示，确认后继续系统RSA授权或无线配对引导。端口不可达与授权不足分开反馈，提示每次启动最多一次，不反复打断；仅启动采集，不自动开启上报、悬浮或车辆/HA控制。开机恢复已启用后台功能，不抢占前台；网络或adbd未就绪时退避重连。APP、ADB授权、车辆接口、悬浮权限分别判断；连接成功不等于接口权限已验证。

| 信息 | 用户定制仪表盘、数据预设、实体与设备组件 |
| 悬浮窗 | 上方全宽悬浮条预览，下方连续模块列表，不模拟系统状态栏 |

汉堡导航默认收起，Header与汉堡同高。信息页用铅笔切换布局编辑，只有编辑模式出现添加组件和组件唯一铅笔入口。删除和尺寸选择在编辑器中，位置通过长按拖动。移除左右箭头、直接删除、右下角尺寸按钮及组件顶边动态短斜纹。

设置的外观区提供“主页显示大小”双档按钮：“放大”以用户指定的0.7.3车机运行截图为尺寸基准，保持当前组件大小，“标准”在宽屏主页横向、纵向各增加一格容量，组件及其文字、图标、曲线、边框和间距等比例缩放。初始选择标准，切换立即保存；保留组件类型、跨度、数据及保存位置，重新排布不改写这些配置。只影响主页内容，不缩放Header、设置、编辑器或悬浮条。

## 组件与实体

默认数值组件为标题、数值、单位；图标可选、可关闭，新建不自动添加。固定网格，1×1为迷你、2×2为正常，按类型提供1×2、2×1、2×4、4×2等尺寸。12种只读样式、7种实体样式及11个数据预设，详细配置见[组件说明](信息组件与历史.md)。

用户在仪表盘主动添加并保存实体后，才能在APP通过实体功能或详情控制。来源包括车辆本地实体和HA现有实体；主页与悬浮条均能显示HA状态或属性，悬浮条保持只读。HA实体按实际服务与功能适配，不自动加入全部实体；未知能力只读。接入、类型、权限、反馈及离线规则见[HA实体接入](HA实体接入.md)。

添加组件改为“选择数据/实体 → 选择兼容组件 → 配置预览 → 保存”；预设直接预填草稿而非新增一套流程。统一选择器支持车辆/HA来源、搜索、连续分类列表、已选查看、状态/属性绑定。调用处决定单选/多选，选择后返回原配置；悬浮模块直接进入模块配置。完整操作规则见[组件添加与数据选择](组件添加与数据选择.md)。

没有独立车辆控制菜单、Header按钮、设置按钮或全量控制面板。设备组件只包含用户选定实体；列表允许混合读数与控制。参考HA Tile、Entities与实体详情，根据可靠反馈和已允许参数呈现开关、选项、动作、数值控制；单参数动作不扩大成任意滑块。

编辑、选择和预览不发送命令，不开启上报或自动写入。已发送不等于已确认，不用请求值乐观改写当前状态。本地车辆操作不依赖HA；HA远程车辆实体不要求先加入APP仪表盘。车辆权限、参数、接口兼容性及反馈由原生统一执行器校验；用户明确取消APP车辆操作的P挡限制，不再自行按挡位阻断。APP操作HA其他实体依赖HA连接、用户权限和实体能力，不使用车辆SDK；HA镜像车辆实体仍遵守既有车辆限制。

时间显示三选一：不显示、上次更新时间、上次变动时间，默认不显示；使用“XX秒/分钟/小时/天前”，不加变动差值和冗余描述。每个组件最多显示一种时间。观察起点及断链规则见[时间口径](信息组件与历史.md#组件时间显示)。

“10 · 添加组件”使用正式小组件渲染真实数据；典型预览包括GB电流、动力电池功率、电池温度、电控温度、低压电压、固件及实际实体状态。可见预览临时订阅共享缓存，关闭分别释放；不自动记录历史。历史预览读取已有本地记录，缺失时为空，不伪造。Figma使用可追溯归档快照，不能称实时数据。

## 悬浮条

默认在顶部状态栏高度内，以整个屏幕水平中心对齐。首次无模块、无预设；每组由用户选择icon、车辆或HA数值/状态/标量属性、单位（支持自定义）及对齐；无单位状态不放单位占位。背景不透明度仅作用于背景，文字和图标独立保持清楚。

真实单击后按住解锁拖动，可移至屏幕任意位置；闲置自动锁定，锁定点击穿透，保存位置。真实触摸手势须实机验收，结果见开发状态；不能凭ADB注入证明真实触摸验收。

## 数据、上报与历史

订阅优先，字段需求及缓存共享，少用轮询；上报随实际车辆变化，合并短时间变化，不人为提高频率。连续分类列表逐条选择，未知分类归未知，X样式复选框；不以散乱卡片拼接数据清单。

历史统一本地SQLite记录，与HA/MQTT连接状态无关。仅对配置的仪表盘字段记录，保留真实时间、质量、断链、来源和解释版本。绘图按像素需求抽取代表点，不固定抽成10秒一次；背景表示时间桶的真实最小/最大，中线保留真实变化，不编造点或连接不同来源。

HA传感器数值保留JSON数字，文本保留文本；同一SkyInfo设备承载传感器及原生控制实体。HA REST的state文本格式不作为数据类型错误的依据。HA/MQTT远程控制默认关闭、鉴权、固定白名单、有效期和不重放规则见[HA控制](HA控制.md)、[MQTT控制](MQTT控制.md)。

HA连接允许配置合法的HTTP／HTTPS域名或IP地址，优先HTTPS，不使用固定IP白名单限制HTTP。使用HTTP时提示一次连接未加密；确认后，同一连接的保存、启动和自动重连不重复提示。不把合法HTTP地址误报为“地址无效”，也不自动改成服务器未支持的HTTPS。当前实现与验证进度见[开发状态](开发状态.md)。

## 公开连接与兼容性

HA/MQTT地址使用空值和连接引导，不预填测试用户的私有地址。每台安装生成并持久化独立设备标识，默认实体前缀及MQTT主题由该标识派生，可由用户修改。更换HA服务器需要重新绑定原HA组件；保存前说明影响，不自动按同名实体迁移。

HA按钮、场景等动作实体的unknown仅表示没有状态记录，不因此禁止执行有效动作；unavailable、实际断线、无权限与缺失服务仍按真实情况处理。有状态实体不会将unknown当成0、关闭或有效反馈。

自定义MQTT明确选择TLS或普通TCP，默认TLS；普通TCP使用未加密连接的一次提示。TLS仍校验证书与主机名。HA恢复可配置Birth主题与在线载荷，另提供重新连接入口；不周期全量重发或伪造恢复。

车辆使用当前安装的Android用户与已授权桥接实际身份，不写死user 10或shell UID 2000，通过本机网络ADB启动打包的app_process桥接。兼容性依据实际SDK读写方法与适配协议，完整固件版本只保留诊断信息，不作为唯一阻断条件。不跨协议盲目套用字段。取消APP所有车辆控制的P挡限制，SDK实际权限、固定动作及参数、返回错误与反馈规则保持。

历史继续使用内置SQLite轻量数据库，容量200MB，不设置记录条数上限。使用文件型SQLite；关闭跨启动保留时使用本机缓存文件，新会话清理，避免200MB历史常驻内存。按用户保留时长清理，达到容量预算时回收最早记录并保留断链事实；不得通过固定条数提前截短历史。实际资源与验证见开发状态。

## 解释规则与验证

GB电流`(raw−30000)/10 A`，动力电池功率`电池包电压×GB电流/1000 kW`，正放负充；三项电池温度`raw−30 °C`。压缩机/PTC为W，ENGINE_POWER名为动力功率、单位kW直读；前电机转速反号、后电机转速直读，单位rpm；两路侧电流A。已确认的单体电压mV及各温度单位直读。完整规则及依据只在[字段转换与单位](字段转换与单位.md)维护。

未确认单位不猜测；充电量与所需电流仍待下次有区分度的充电采样求证。保留raw、换算版本和依据。用户确认单位不等于独立物理标定，压缩机/PTC/水泵读数不能单独推断热泵模式或支路。

控制目录173项：39项已有实测依据，134项推测、仍标记待验证。取消推测控制按钮、配置及远程开关操作；全部已归档控制直接使用现有执行计划，不再要求先开启推测控制。不扩大当前固件已允许参数，不自动执行新候选。命令接受、软件状态读回和物理效果分开验收。

## 视觉、动效与语言

所有UI/UX开发遵循固定submodule的[Fluorite Design](design/fluorite-design/DESIGN.md)，交付按[REVIEW](design/fluorite-design/REVIEW.md)验证；车机尺寸、组件网格和操作约束只在[宿主DESIGN](../DESIGN.md)维护。APP自适应系统浅/深色。E保留为采用前的视觉来源，不能作为并行规范；当前实现差异与未测项见[开发状态](开发状态.md)。

界面文案从独立语言文件读取，字段ID、动作ID、单位、Topic、用户自定义名称不随语言变化；当前只提供简体中文，翻译与完整多语言界面另行验收。

启动器图标采用用户2026-10-13提供的黑底、白色几何信息符号和右上黄色方块，在SkyInfo唯一Figma Page保留可编辑矢量源；Android同时提供传统、自适应及单色资源，不直接缩放整张参考截图。
