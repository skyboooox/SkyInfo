# 产品需求

SkyInfo 显示原车隐藏或不便查看的信息，支持自定义仪表盘、顶部悬浮条和 HA/MQTT。默认展示不重复原车容易查看的车速、SOC、挡位。Flutter 主界面，Android 原生运行层；包名 `app.skyinfo.vehicle`。

## 页面与导航

| 页面 | 职责 |
| --- | --- |
| 信息 | 仪表盘、预设、只读与控制实体组件 |
| 悬浮窗 | 上方全宽悬浮条预览，下方模块配置；不模拟状态栏 |
| 连接 | 默认 HA：实体接入、车辆上报、远控分别配置；自定义 MQTT 在高级设置 |
| 设置 | 外观、权限、启动、采集、连接、历史和诊断 |

汉堡导航默认收起，Header 与汉堡同高。铅笔切换布局编辑，编辑模式才显示添加组件和组件的唯一铅笔；删除、尺寸在编辑器中，长按拖动位置。车辆控制通过仪表盘实体及详情提供。

主页默认“标准”，保留已保存档位。“放大”使用基础网格，“标准”横竖各增加一格容量，卡片内容等比例缩放；不缩放 Header、编辑器或悬浮条。尺寸见[宿主设计](../DESIGN.md#主页显示大小)。

## 版本与项目入口

发行渠道由构建时的 beta/stable Flavor 决定，默认 beta，不提供运行时切换。beta 的设置页顶部常驻“正在使用测试版”、实际版本号和“地球图标 + 版本与更新”跳转按钮，进入任意设置分类都可见，不弹启动确认；正式渠道隐藏测试提示，渠道不由 debug/release 编译方式判断。

车辆适配检查及其逐字段原值日志只随 beta 打包；stable 不注册该调用。诊断信息、实体映射、权限/连接恢复、字段原值与待验证标记属于正常功能，两渠道均保留，不按渠道缩减车辆控制能力。渠道与编译模式分别记录，配置导入不能改变渠道。构建方法见[构建与发布](构建与发布.md#发行渠道)。

设置 → 常规 → 关于显示安装包实际版本，并提供 GitHub 项目入口 `https://github.com/skyboooox/SkyInfo`，显示完整地址并由系统浏览器打开。没有处理应用或打开失败时就地提示，保留当前页面；不自动连接、授权或上报。

## 组件与悬浮条

默认组件为标题、数值、单位；图标可选，时间默认隐藏。固定跨度，1×1 迷你、2×2 正常；提供 12 种只读样式、7 种实体样式和 11 个预设。时间只能选更新时间或变动时间之一，显示“12秒前”等相对年龄。

创建流程：数据/实体 → 兼容组件 → 配置预览 → 保存。预设预填同一份草稿；选择器使用连续分类/数据列表、X 复选框，支持车辆与 HA 混选。APP 预览使用真实缓存，缺失显示“—”，历史只读取已有记录。细节见[组件](信息组件与历史.md)与[创建流程](组件添加与数据选择.md)。

APP 控制只在已保存的仪表盘实体及详情中提供；编辑、预览和悬浮条只读。HA 远程车辆控制无需先加入 APP 仪表盘。请求值不乐观覆盖当前状态，反馈按真实来源更新。

悬浮条初始无模块，默认在状态栏高度内、屏幕水平居中。每组自选图标、字段、单位和对齐；背景透明度只作用于背景。单击后按住拖动，闲置锁定并点击穿透，位置持久保存。

## 启动与授权

每次启动恢复采集并检查本机网络 ADB。默认 `127.0.0.1:5555`，支持本机地址、TCP 授权和无线配对；首次 RSA 确认或配对由用户完成。未授权与端口不可达分别提示，每次启动最多一次；系统调试开关由车机提供。开机恢复已启用后台功能，不抢占前台；未就绪时退避重连。不自动开启上报、悬浮或远控。见[网络 ADB](网络ADB授权.md)。

## 采集、历史与连接

订阅优先，需求与缓存共享，轮询仅作用户配置的降级方案。上报跟随实际变化并合并，不固定周期重复上传全量缓存；主页字段与上传选择独立。

历史统一本地 SQLite，仅记录仪表盘字段，与 HA 连接无关。容量 200 MB，不限条数；按保留时长及容量淘汰。跨启动保留默认关闭，使用会话缓存文件。曲线保留实际样本与真实断点，背景表示时间桶最低/最高；规则见[历史](信息组件与历史.md#主页历史)。

HA 允许 HTTP/HTTPS 域名或 IP，优先 HTTPS；MQTT 明确选择 TLS/TCP，默认 TLS。未加密连接保存时提示一次，重连不重复；TLS 校验证书与主机名。服务器默认空值，每台安装生成独立设备标识。更换 HA 服务器需重新绑定实体。HA 动作实体 unknown 不误当离线；车辆传感器数值以 JSON 数字上报。协议见[HA 控制](HA控制.md)、[HA 接入](HA实体接入.md)和[MQTT](MQTT控制.md)。

## 兼容性与资源

车辆按当前 Android 用户、实际权限、协议及 SDK 方法适配；固件字符串仅作诊断，不设置 APP P挡门槛。固定控制计划中的推测项直接可执行，但保留待验证标签；参数与确认等级不因执行自动扩大。

只内置确认的换算，保留 raw、来源和解释版本；单位未知保留原值。定义只在[字段转换与单位](字段转换与单位.md)维护，支持范围与未测项见[验证与兼容性](验证与兼容性.md)。存储格式与升级规则见[构建指南](构建与发布.md#版本与升级)。

UI/UX 遵循 [Fluorite Design](design/fluorite-design/DESIGN.md)，平台差异在宿主设计维护。适应系统浅深色，支持减少动画。语言资源独立，当前简体中文；字段/实体 ID、单位、Topic 和自定义名称不随语言改变。启动器为黑底白色几何符号与黄色方块，提供传统、自适应和单色资源。
