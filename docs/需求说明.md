# 产品需求

SkyInfo 是 Android 车机信息仪表盘，用于查看原车隐藏或不便查看的数据，配置顶部悬浮条，并连接 Home Assistant 或 MQTT。Flutter 承载界面，Kotlin 承载设备能力；包名 `app.skyinfo.vehicle`。

## 页面与导航

| 页面 | 职责 |
| --- | --- |
| 信息 | 自定义仪表盘、预设、只读与控制实体组件 |
| 悬浮窗 | 全宽悬浮条预览、模块及显示配置 |
| 连接 | HA 实体接入、车辆上报与远控；高级自定义 MQTT |
| 设置 | 外观、权限、启动、采集、连接、历史和诊断 |

汉堡导航默认收起。信息页仅在布局编辑时显示添加按钮和组件铅笔；删除在编辑器内，位置通过长按拖动。车辆控制作为仪表盘实体提供，不另设车辆控制页。默认展示不重复原车容易查看的车速、SOC、挡位。

主页默认标准档，参考车机为8列×3行正方格；放大档使用基础网格。保留四周16dp边距，只缩放卡片内容，导航和配置界面维持独立尺寸。计算规则见[宿主设计](../DESIGN.md#主页显示大小)。

## 组件与悬浮条

提供12种只读样式、7种实体样式及11个预设。默认结构是标题、数值和单位，图标及时间可选；更新时间、变动时间互斥。创建、编辑、选择与真实预览共用同一套流程，见[操作说明](组件添加与数据选择.md)；样式、固定尺寸、刷新指示和本地历史见[组件说明](信息组件与历史.md)。

APP 控制仅在已保存的仪表盘实体及详情中提供；编辑、预览和悬浮条只读。请求目标与实际状态分开，反馈按真实来源更新。HA 远程车辆控制无需先加入 APP 仪表盘。

悬浮条初始无模块，默认位于状态栏顶部中央。每组自选图标、字段、单位和对齐；通过实际窗口拖动调整位置，闲置锁定并点击穿透。设置提供显示、位置、字号和背景不透明度，操作规则见[悬浮条模块](组件添加与数据选择.md#悬浮条模块)。

## 启动与连接

每次启动恢复采集并检查本机网络 ADB；首次 RSA 确认或无线配对由使用者完成。默认连接本机，不自动开启上报、悬浮或远控。开机按已启用的后台功能恢复，不抢占前台。可选“自动开启系统ADB”默认关闭；连接方式、权限、网络条件与失败恢复见[网络 ADB](网络ADB授权.md)。

默认连接 Home Assistant，自定义 MQTT 位于高级设置。HA 实体接入、车辆上报和远控分别启用；服务器默认空值，每台安装使用独立设备标识。HTTP/HTTPS 与 MQTT TLS/TCP 均可配置，未加密连接保存时提示一次。更换 HA 服务器须重新绑定实体。协议分别见[HA 实体接入](HA实体接入.md)、[HA 车辆控制](HA控制.md)与[MQTT](MQTT控制.md)。

采集订阅优先，字段需求与缓存共享，轮询仅作为配置的降级路径。上报跟随真实变化合并，主页选用与上报选择独立。历史统一本地 SQLite，仅记录仪表盘字段，与 HA 连接无关；容量200MB，不限条数，跨启动保留默认关闭。

## 外观与渠道

UI/UX 遵循固定 [Fluorite Design](design/fluorite-design/DESIGN.md)，平台差异在[宿主设计](../DESIGN.md)维护。自动主题优先跟随车机实际浅深状态，读取失败时跟随 Android；手动选择优先。背景是统一大小的静态实心圆点，页面保留轻柔过渡，减少动画时关闭非必要动态。

alpha/beta 设置顶部显示测试版提示、实际版本和“版本与更新”外链入口；专用适配检查集中在实验室。stable 隐藏测试提示、实验室及逐字段调试日志，保留正常权限、诊断、连接恢复和控制能力。关于页始终提供 [GitHub 项目入口](https://github.com/skyboooox/SkyInfo)。渠道与版本规则见[构建指南](构建与发布.md#发行渠道)。

## 数据与适配

车辆按当前 Android 用户、实际权限、协议和 SDK 方法适配，不以完整固件字符串或固定 UID 决定能力，不设 APP P挡门槛。固定计划中的推测项保留待验证标记；接口接受、软件读回与物理效果分别判断。

只内置确认的换算，保留原值、来源和解释版本；单位未知时保留原值。海拔读取车机 GNSS，按需被动订阅，不记录经纬度。字段定义见[转换与单位](字段转换与单位.md)，支持范围和未测项见[兼容性](验证与兼容性.md)，数据处理见[隐私说明](隐私与数据.md)。

语言资源独立，当前为简体中文；稳定 ID、单位、Topic 和自定义名称不随语言变化。
