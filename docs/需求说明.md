# 功能与默认行为

SkyInfo 的页面与详细操作分别维护，本文定义入口和默认行为。运行条件及实测范围见[兼容性说明](验证与兼容性.md)。

| 页面 | 职责与操作说明 |
| --- | --- |
| 信息 | 自定义仪表盘、只读与控制实体[组件](信息组件与历史.md)，[创建、编辑与选择](组件添加与数据选择.md) |
| 悬浮窗 | 全宽只读悬浮条预览及[模块配置](组件添加与数据选择.md#悬浮条模块) |
| 自定义分屏 | [快速选择左右应用、保存组合及显式启动](自定义分屏.md) |
| 连接 | [HA 实体接入](HA实体接入.md)、[车辆上报与远控](HA控制.md)，高级[自定义 MQTT](MQTT控制.md) |
| 设置 | 外观、权限、启动、采集、连接、[本地历史](信息组件与历史.md#主页历史)与诊断 |

汉堡导航默认收起。仪表盘默认标准档，布局与缩放见[宿主设计](../DESIGN.md#主页显示大小)；车速、SOC、挡位等原车常见信息不预置到仪表盘。车辆控制由已保存的仪表盘实体及详情提供；编辑、预览与悬浮条只读，HA 远控无需先加入仪表盘。

## 启动与连接

每次启动恢复采集；[本机网络 ADB](网络ADB授权.md)未处于授权暂停时自动检查连接。首次 RSA 或无线配对由使用者完成，需要授权时跨重启保留暂停。开机按已启用的后台功能恢复，不抢占前台；默认启动页面为信息，可在[常规设置](自定义分屏.md#启动页面)选择。

默认连接 Home Assistant，服务器地址为空；实体接入、车辆上报和远控独立启用，不自动开启上报、悬浮或远控。每台安装有独立设备标识，更换 HA 服务器须重新绑定来源。HTTP/HTTPS 与 MQTT TLS/TCP 的保存及恢复规则见各连接文档。

悬浮条初始无模块。历史统一本地 SQLite，与 HA 连接无关，仅记录仪表盘需求；保留、容量及异常退出边界见[记录规则](信息组件与历史.md#主页历史)。

## 外观与数据

主题默认自动，手动选择优先；车机主题映射与平台视觉差异见[DESIGN](../DESIGN.md)。测试提示、实验室及正式渠道边界见[发行渠道](构建与发布.md#发行渠道)。

字段保留原值、来源及解释版本，只采用确认换算；单位未知时保留原值。采集、权限和固定控制计划见[适配机制](车辆数据适配.md)，数据使用见[隐私说明](隐私与数据.md)。

当前语言为简体中文；语言资源独立，稳定 ID、单位、Topic 和自定义名称不随语言变化。
