# 隐私与数据

SkyInfo 按用户配置的仪表盘、悬浮条与上报字段合并采集需求。没有预选上传字段；不内置维护者的服务器、令牌或设备名称。

历史保存在应用沙盒内的 SQLite 文件。HA/MQTT 仅连接用户指定的服务器；远程控制默认关闭。独立设备标识用于实体归属，可在配置中管理。网络 ADB 使用每台安装独立生成的密钥，密钥不进入配置导出。

HTTP 和普通 MQTT TCP 是未加密连接，选择时提示一次。HTTPS/TLS 校验证书与主机名。连接方式由实际网络环境决定。

悬浮窗由系统单独授权。可选的 ADB 自动恢复只在启用后操作系统调试开关及当前 APP 用户的设置写入权限，权限与关闭行为见[网络 ADB](网络ADB授权.md#调试开关恢复)。

海拔需当前用户授予精确定位权限；拒绝仍可使用其他实体。按选用需求被动订阅，并使用定位前台服务；只保留高度、精度、基准及采样时间，不记录经纬度，不主动开启系统定位。

自动主题使用车机设置读取权限，订阅显示模式与昼夜状态，仅用于本机外观同步。

配置导出与诊断报告仍应在分享前人工检查。公开反馈请移除地址、凭据、个人实体名称、设备标识、车屏和原始采样。公共测试使用匿名回归数据和模拟服务，与用户实时数据分开。
