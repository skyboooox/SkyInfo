# 开发状态

当前源码：0.8.2+45，开发验证阶段。功能与默认值见[需求说明](需求说明.md)，验证范围见[兼容性与验证](验证与兼容性.md)。

## 当前实现

信息、悬浮窗、连接、设置四页已实现。仪表盘支持只读与实体控制组件、跨车辆/HA 数据选择、实际数据预览、标准/放大和本地历史。车辆控制通过用户主动添加的实体操作，无独立控制菜单。

网络 ADB 由应用内置，独立 RSA 密钥、TCP 授权、无线配对配置、app_process 桥接和断线恢复已实现。应用启动恢复采集，检查本机连接，未授权/不可达分别提示一次；默认标准并保留用户已保存档位。

HA/MQTT 提供明确连接方式、逐字段上报、统一设备实体与固定计划控制。历史使用本地 SQLite，容量预算 200 MB；解释版本、单位和断链保留。UI 使用固定 Fluorite 规范，语言源独立。

## 未完成实机覆盖

- 0.8.2 新启动引导、冷启动、OEM 启动器图标和长时间运行尚未独立实车验收。
- 内置网络 ADB 的 Android 无线配对及新链路真实悬浮条触摸需继续验证。
- 控制目录 173 项中，134 项仍是推测计划；39 项有历史实测依据，不代表全部物理功能或所有车型通过。
- 充电量、所需电流等未确认字段继续保留原值；跨车型/固件兼容性需逐项核对。
- 当前只提供简体中文；不同屏幕、Android 用户与系统调试实现的覆盖有限。
