# 组件与本地历史

默认结构为标题、数值、单位；图标与时间可选，无单位状态/文本不占单位位。创建与编辑见[操作流程](组件添加与数据选择.md)，平台尺寸见[宿主设计](../DESIGN.md)。

## 展示样式

| 样式 | 数据数量 / 类型 | 展示结构 | 可配置内容 |
| --- | --- | --- | --- |
| 数值 | 1项数值 | 标题 + 大数值 + 单位 | 数据、单位、小数位、字号、尺寸 |
| 状态 | 1项状态 | 标题 + 状态文本 | 数据、已确认状态映射、未知状态、尺寸 |
| 文本 / 枚举 | 1项文本或枚举 | 标题 + 文本 / 枚举名称与原值 | 数据、换行、枚举显示、尺寸 |
| 双值对比 | 2项 | 同一组件中并排的两个标题、数值、单位 | 分别选择两项、标签、顺序、布局、各项单位 |
| 实体列表 | 建议2–8项 | 一行一个实体，名称左对齐、值与单位右对齐 | 逐项数据、标签、可选图标、顺序、行距、各项单位 |
| 实体概览 | 建议2–8项 | 多个独立实体按2/3列排列 | 逐项数据、列数、顺序、标签、各项单位 |
| 范围条 | 1项有明确显示范围的数值 | 数值、单位、横向范围条与上下界 | 数据、上下界、范围来源、尺寸 |
| 仪表 | 1项有明确显示范围的数值 | 半圆范围仪表、当前值与单位 | 数据、上下界、范围来源、尺寸 |
| 趋势 | 1项数值 | 当前数值与单位 + 代表值实线、极值背景带 | 数据、时间窗口、纵轴、精度、尺寸 |
| 状态列表 | 建议2–8项状态 | 逐行显示各实体的状态 / 质量 | 逐项数据、显示属性、已确认映射、顺序 |
| 历史对比 | 建议2–4项同单位、同解释口径的数据 | 共享时间轴的各项实线、极值背景带与图例 | 逐项数据、时间窗口、单位一致性、纵轴、曲线区分 |
| 状态时间线 | 1项离散状态 | 当前状态 + 按时间排列的状态区段 | 数据、时间窗口、状态映射、尺寸 |

多字段各自保留单位、来源、质量与时间，一项失效不清空其他项。范围条/仪表上下界是显示范围，不代表安全阈值。历史共轴只接受同单位、同解释口径，双值不自动计算差值。

## 实体控制

| 组件 / 功能 | 使用条件 | 交互 | 尺寸 |
| --- | --- | --- | --- |
| 实体卡 | 单个传感器或控制实体 | 名称/状态打开详情；功能区单独操作 | 2×1、2×2，默认2×2 |
| 开关 | 已确认双态写入及可靠状态反馈 | 显式切换；发送期间禁用，实际状态等待读回 | 实体卡内或列表行内 |
| 选项 | 已确认离散枚举 | 当前选项、下拉选项列表；只列允许值 | 实体卡内或列表行内 |
| 动作按钮 | 瞬时动作、无可靠双态反馈或单一固定参数 | 显式点击；点动按住执行、松开/失焦停止 | 实体卡内或列表行内 |
| 数值控制 | 已确认完整范围、步长、单位、反馈 | 加减/输入；提交校验，不能用显示单位换算写参数 | 实体卡内；复杂输入用2×2 |
| 混合实体列表 | 用户选定的多项传感器与控制 | 连续行，各行独立状态和功能，不提供全组开关 | 2×2、2×4、4×2 |
| 设备组合卡 | 用户选定的同设备实体 | 设备标题下连续实体行，不自动加设备全部功能 | 2×2、2×4、4×2 |

只读字段不因外观变成控制。可靠范围才能提供数值输入；单参数动作保持按钮。编辑/预览禁用动作，正常浏览按实际权限与固定参数执行；请求值不替代反馈，1×1 不承载复杂控制。

## 固定网格

尺寸为列×行，1×1 迷你、2×2 默认正常，按格吸附。适用范围：

| 样式 | 支持尺寸 |
| --- | --- |
| 数值、状态、文本/枚举 | 1×1、1×2、2×1、2×2 |
| 双值对比 | 1×2、2×1、2×2、4×2 |
| 实体列表、实体概览、状态列表 | 2×2、2×4、4×2 |
| 范围条、状态时间线 | 2×1、2×2、4×2 |
| 仪表、趋势、历史对比 | 2×2、4×2 |

宽高 = 基础格×跨度＋间距×(跨度−1)。选择尺寸只显示网格图标，保留无障碍名称；超长列表可滚动，长文本换行或滚动。编辑模式仅一个铅笔，删除在配置器中，位置长按拖动。

标准/放大保留跨度、字段、时间与保存位置，只改变显示网格和统一缩放；参考视口与计算只在 [DESIGN](../DESIGN.md#主页显示大小) 维护。

## 图标与预设

图标默认关闭；标题图标与逐项图标分别设置，没有图标不留空位。双值、列表、概览、状态列表及历史对比支持逐项图标。按图形名称/分类搜索，推荐映射不改变名称、单位或有效性，见[图标库](../design-assets/icons/README.md)。

11个预设：低压电压、压缩机读数、热管理、电池温度、电芯电压、电机与电控、固件版本、数据可用性、电池温度历史、电池电流 · GB、动力电池功率。只在选择后预填草稿，不开启上传/控制；数值沿用[字段转换](字段转换与单位.md)。

## 真实预览

样式缩略图与配置预览复用正式组件、真实缓存及临时需求租约，关闭后释放。缺失显示“—”，历史不足显示已有片段或空状态；不额外轮询、上传或记录历史。典型组合：

| 预览形式 | 典型条目 | 单位 / 内容 |
| --- | --- | --- |
| 默认数值、迷你数值 | 电池电流 · GB；动力电池计算功率 | 已换算A；电压×GB电流÷1000 kW，正放负充 |
| 双值对比 | 电池最高温度、最低温度 | 已内置换算的°C |
| 实体列表 / 热管理预设 | 压缩机功耗、PTC功耗、发动机水泵转速 | W、W、rpm |
| 实体概览 / 电机预设 | 前后电机温度、前后IPM温度 | °C；保留各自来源 |
| 范围条 / 仪表 | 低压电压 | V；沿用明确的显示范围，不冒充厂商安全阈值 |
| 趋势 | 动力电池计算功率或低压电压 | 真实本地历史与当前值 |
| 历史对比 | 电池最高温度、最低温度 | 同时间轴的真实本地°C历史 |
| 状态、文本 / 枚举、状态时间线 | 双区分控、出风组合等有可靠读回的实体 | 已确认状态 / 枚举；时间线仅用已有状态历史 |
| 数据可用性 | 上述代表字段 | 实际有效 / 不可用状态 |
| 控制实体 | 前除霜、空调循环、前排设定温度 | 真实读回；预览只展示，不执行动作 |

Figma 用快照或示意，APP 用实际缓存；设计入口统一在 [Figma](Figma设计.md) 维护。

## 组件时间显示

单选：不显示（默认）、上次更新时间、上次变动时间。更新时间为最近有效样本接受时间；变动时间为有效值实际改变的观察时间，同值更新不刷新。

| 年龄 | 格式 |
| --- | --- |
| <60秒 | 完整秒数，向下取整；不到1秒为0秒前 |
| <1小时 | 完整分钟数 |
| <24小时 | 完整小时数 |
| ≥24小时 | 完整天数，不切换月/年 |

仅显示“12秒前”等年龄，未知或不可信未来时间为“—”。单值显示一条，多值分别显示同一种时间。失效保留最后有效时间；质量在可用性组件/诊断中显示，无效值不冒充当前值。

比较发生在显示舍入之前；重绘、格式、历史查询、上传、重连或质量变化不制造数值变动。首次有效值建立观察起点，来源/会话/解释改变重建基准。可信源时间单独保留，无源时间使用接收时间，不推测未观察的中间变化。

可见组件共享年龄调度，按秒/分/小时/天显示边界重绘，后台暂停；不增加车辆轮询、历史查询或网络请求。

## 主页历史

所有连接模式读取本地 SQLite，与 HA/MQTT 无关。仅记录仪表盘字段，同字段共享一份；移除最后一个消费者停止新增，悬浮/上报/预览不自动记录。保留值、raw、单位/解释版本、来源、质量及源时间戳。

默认最近30分钟，窗口可选5/15/30分钟或2小时；窗口与保留期限分别配置。容量200MB、不限条数，按期限及容量淘汰，显示实际覆盖时间。跨启动保留默认关闭，使用会话缓存文件；开启时用持久数据库，切换保留本会话记录。清空仅删除本机历史。

### 折线与极值背景

实线保留查询窗口的全部有效实际样本及时间，不固定抽成10秒一点。时间桶仅用于背景极值：每桶独立矩形，上沿最高、下沿最低，不跨空桶插值、不填到零轴，纵轴包含极值。多字段分别计算，不将空间最高/最低合并成时间极值；单点或同值范围自然收合。

连续样本按真实时间线性连接。连续阈值为本段正时间间隔中位数×3，限制5–30秒；更长间隔保持最后已知状态至真实更新。边界裁切/状态保持不生成数据库样本，也不表示收到持续采样。

不可用、暂停、移除、失效、断链及来源/单位/解释变化分段。稀疏有效订阅跨空桶保持已知值，空桶不等于断链，不补造样本或峰谷。无原始样本或可信极值时只画实线。

每字段保留一条窗口前状态作边界，计入容量。仅记录会话仍启用且末状态有效时延长至查询快照；暂停、失效或旧会话不延长。图表时间轴固定于查询快照，状态/质量变化最多每5秒合并查询，同值只更新时间不触发；保留分钟级窗口刷新，离页取消。

图表与聚合不改变采集或上报频率，不能恢复未收到或已淘汰的峰谷。状态时间线使用离散区段，不使用数值极值带。
