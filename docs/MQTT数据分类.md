# 连接数据分类与逐条选择

目录含92项，含1项计算功率。单位规则见[字段转换](字段转换与单位.md)，支持范围见[适配](车辆数据适配.md)。上传默认不选。

连接默认Home Assistant，自定义MQTT服务器位于高级设置。两种模式共用字段清单，主页选用不自动勾选上传。

## 分类规则

界面使用一个容器中的分类列表与逐条数据列表，名称、数量、单位和更新方式按列对齐，以细分隔线组织。复选框选中时框内为X；分类导航不代替逐条选择，不拼接独立色块或用分类开关批量替代字段选择。

按数据所属的车辆系统分类。电池温度归动力电池，电机/IPM温度归电机与电控，DC/DC归低压与供电，发动机水泵与节温器归发动机与传动，压缩机/PTC归空调与热管理。充电连接与补能状态归充电与补能。

每个字段只归一个主分类；可用标签搜索，但分类不改变来源、单位或枚举。无法确定所属系统的条目归未知；未知单位、无效读数和订阅未验证不使已知系统的字段变成未知分类。未知当前为空，不编造字段填充空状态。后续新读取字段先登记来源，再分类；分类改名不改变稳定字段标识或既有选择。

分类计数只统计字段目录，不把静态SET/控制入口当作遥测选项。每条默认不选；来源已定位但权限、有效性或更新未验证的条目保留状态，不能标成已支持。

## 逐条选择与来源

最高、最低、平均以及各轮位均是不同选择项。相似通道保留各自条目；不同tx、SDK后处理、底层原值和SDV字段不得视为同一编码。原生地址是device / transaction / FID，负FID合法。tx5是int32、tx7是float32。实际SDK事件订阅应登记其类、featureID、回调和转换；下表原生标识用于追踪来源；实测注册与回调状态按车辆数据适配记录区分。SDV字段以完整RPC与响应字段路径登记，复合响应需拆成逐条选项。

“原值”是界面编码状态，不是物理单位；自定义MQTT的unit未知时为空，raw及类型仍保留；HA实体不填写未经确认的unit_of_measurement或device_class，原值与来源通过属性保留。转换与无效规则见字段说明。瞬时油耗选择数值时必须自动依赖配对单位，依赖只用于解释，未被勾选的独立单位项不因此成为额外上传项。SOC与挡位可由用户选择上传，不因此加入信息页或悬浮条。

## 更新与发布规则

动态字段优先订阅；订阅可用性与实际回调频率按运行身份和设备分别验证。没有可用订阅的字段才启用按字段的保守低频回退；订阅尚未验证不等于不支持，应先核对，不能默认同时启动订阅和轮询。无权限不启动忙循环。静态字段连接时读取。HA与MQTT均使用各字段自身更新节奏，变化合并进入待发队列；HA按实体更新，MQTT可按变化批次发布，避免固定周期反复上传全量缓存。心跳与车辆采样分离。完整生命周期、质量与缓存策略见[项目规划](项目规划.md#数据流)。

充电量与所需电流仍待充电工况验证；状态和单位见[字段转换](字段转换与单位.md)。
