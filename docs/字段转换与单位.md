# 字段转换与单位

原生采集统一解码，主页、悬浮条、上报及本地记录共用结果；保留 raw、解释版本、依赖时间和来源。单位和换算定义的确认不等于独立物理标定，不猜测未确认倍率。

| 字段 | 解释 | 定义状态 |
| --- | --- | --- |
| 电池包电压 / 电池电流 · 旧通道 | V / A 直读 | 单位已确认 |
| 电池电流 · GB | (raw−30000)/10 A | 换算已确认 |
| 动力电池功率 | 电压×已换算 GB 电流/1000 kW，正放负充 | 计算项，保留两路 inputs |
| 电池最高 / 最低 / 平均温度 | raw−30 °C | 换算已确认 |
| 单体最高 / 最低电压 | mV 直读 | 单位已确认 |
| 前 / 后电机转速 | 前侧 −raw，后侧直读，rpm | 符号与单位已确认 |
| 两路电机侧电流 | A 直读 | 单位已确认 |
| 压缩机 / PTC 功耗 | W 直读 | 单位已确认 |
| ENGINE_POWER | 动力功率，kW 直读 | 单位已确认 |
| 电池健康度 | % 直读 | 单位已确认 |
| 发动机水泵 | rpm 直读 | 单位已确认 |
| 已标注电机/IPM、DC/DC、车内/滤波及轮胎温度 | °C 直读，不另加偏移 | 单位已确认 |
| 主驾/副驾设定与车外温度 | 温度单位字段 1 摄氏直读；0 华氏转换 (raw−32)×5/9 | SDK 配对单位 |
| 瞬时油耗 | 单位码 1=L/100km、2=km/L、3=MPG、4=L/h，不改变数值 | SDK 配对单位 |
| 海拔 · GNSS | `location.gnss_altitude`，Android GPS高度直读，m，WGS84椭球基准 | 非平均海平面高度，不应用未知偏移 |
| AEB 激活 | 原始编码，不推断激活状态 | 保留原始编码 |
| BMS 允许功率、充电量、所需电流等未确认项 | 保留原值及待验证标记 | 尚无足够区分度的核对 |

单位依赖未知、失败或断链时不伪装已确认单位。单位变化触发重新解释及语义上报，数值时间仍是实际字段采样时间。计算功率不作为直接功率 FID；不会改变上游轮询频率。

同值更新时间与变动时间分开，零浮点不会因整数表示差异被当成变化。历史只连接同来源、同单位及同解释段，保留真实断点；不得从空调水泵、压缩机或 PTC 的单项数值直接推断制冷/制热支路。

详细 ID 与编码见[数据分类](MQTT数据分类.md)和 `app/assets/catalog.json`。验证范围见[兼容性与验证](验证与兼容性.md)。

GNSS高度使用Android `Location.getAltitude()`，仅接受含有效高度的GPS定位，负值合法；不把缺失高度解释为0。缓存保留定位采样时间，超过120秒标记过期；新回调恢复。被动监听现有定位，不主动启动GNSS或采集经纬度。接口缺失、权限不足、定位关闭或无定位时保留不可用状态，不虚构高度。Android 10+使用WGS84椭球高度，不与海平面高度混用。定义依据[Android Location](https://developer.android.com/reference/android/location/Location#getAltitude())与[被动定位](https://developer.android.com/reference/android/location/LocationManager#PASSIVE_PROVIDER)。
