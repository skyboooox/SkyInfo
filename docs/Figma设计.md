UI/UX 统一遵循固定子模块的 [Fluorite Design](design/fluorite-design/DESIGN.md) 和 [REVIEW](design/fluorite-design/REVIEW.md)，车机差异仅在 [宿主 DESIGN](../DESIGN.md) 维护。

## Desktop Bridge

Figma 读取、编辑、原型检查、截图和资源导出只使用 Desktop Bridge，通过本机原生 Plugin API 操作。Bridge 断开时恢复已有插件，不使用官方 MCP/REST 。设计不是源码构建依赖。

按以下步骤维护设计：

1. 更新功能与宿主说明，读取固定 Fluorite 规范。
2. 打开下列目标文件，恢复已有 Bridge，核对 fileKey、Page 与节点。
3. 保留可编辑文字、矢量、组件实例和原型目标，分段修改并读取实际结果。
4. 用 `exportAsync` 导出受影响浅深画板，再修改 APP 并做行为/视觉回归；节点与验收原件存本机忽略 QA。

## 实时预览与选点提示

连接列表浅深画板（1:6283 / 1:7050）展示数值与单位共用的当前读数区；设计中的功耗与温度为界面快照示例，APP按实际缓存更新，缺失为“—”。新建悬浮模块画板（1:5260 / 1:5299）的“显示小数”默认未勾选，精度选择禁用；已有编辑模块画板表达保存精度。

历史详情（1:12905 / 1:12967）点击或拖动图表进入浅色选点状态（87:65067 / 87:65231）或深色选点状态（87:65423 / 87:65587）。选点状态按[提示时序](信息组件与历史.md#趋势线与极值背景)回到同一详情，连续交互切换选点状态；原型保留详情窗口，APP执行触屏与生命周期计时。设置→连接的车辆上报区域（1:6065 / 1:6174）在HA远程控制下方展示真实订阅状态与实际错误辅助文案；具体状态口径见[宿主设计](../DESIGN.md#悬浮连接与历史)。
