## Desktop Bridge

Figma 读取、编辑、原型检查、截图和资源导出只使用 Desktop Bridge，通过本机原生 Plugin API 操作。Bridge 断开时恢复已有插件，不使用官方 MCP/REST 。设计不是源码构建依赖。

先核对目标文件与 Page，保留文字、矢量、组件实例及原型连接。UI/UX 按文档 → 设计 → 代码 → 验证执行；导出受影响浅深画板，操作节点与检查记录写本机 QA，不公开个人诊断。
