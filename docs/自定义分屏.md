# 自定义分屏

自定义分屏提供快速启动和本机组合管理，对应 [Figma 设计](Figma设计.md#自定义分屏)。APP通过当前用户包管理器查询应用及入口，显式发送启动请求；系统请求结果与实际分屏布局分别判断。

## 页面与组合

汉堡菜单增加“自定义分屏”，与信息、悬浮窗、连接、设置并列。页面顶部提供快速分屏：左右应用可直接点击更换，选择面积方向后显式启动，快速选择无需先保存组合。快速选择与组合编辑使用各自草稿，互不覆盖。快速选择保留在当前进程内，切页及外部应用返回后可继续使用；结束进程后重新选择，不自动启动。下方为已保存组合，每项以紧凑面积图形内的应用名称、组合名称及独立启动/编辑热区呈现；“新建组合”进入独立草稿。首次为空时保留快速选择，并提供创建入口。

比例只提供 `7/3`（左大右小）与 `3/7`（左小右大），始终按左/右顺序解释。界面选择文案为“左大右小”“左小右大”，面积图形表达左右关系。编辑器持续展示真实面积关系；切比例只改面积，左右应用保持原位。“交换左右”仅交换左右应用与其 Activity。名称可编辑，默认由左右应用名生成；重名可保存，以稳定组合 ID 区分，编辑只更新当前组合。

新建、编辑共用草稿；选择器返回保留草稿。左右应用完整且入口有效后才可保存；保存仅持久化组合，返回组合页。取消或放弃更改不保存。删除需确认；保存失败保留草稿并支持重试。组合保存在本机，与 HA 连接状态无关。最多保存64个组合，名称最长128字；配置导入导出包含组合及启动页面，图标不写入配置。

## 应用与 Activity

点击预览内的左/右区域或对应应用行进入单选应用列表。显示当前用户可见的可启动应用，支持按应用名搜索；保留已选项，区分加载、无应用与无搜索结果。应用只读枚举、预览和保存均不启动外部应用。

“高级”开关默认关闭，辅文为“指定 Activity”。关闭时使用每个应用的默认启动入口；开启后分别显示左右入口，点击进入所选应用的 Activity 单选列表。列表显示入口名称及组件标识，仅启用、导出且当前调用者具备所需权限的入口可选；不可用项就地说明原因。技术组件名只在高级详情出现，不以手写任意组件作为常规入口。

更换某侧应用时恢复该侧默认入口，不沿用旧应用的 Activity。关闭高级开关后本草稿恢复两侧默认入口；已保存的指定入口必须仍以开启状态审阅。应用卸载、入口移除、禁用或权限不足时保留组合与名称，标明失效侧并提供编辑修复，禁止用错误入口发起启动。

## 启动与结果

“启动”显式发起外部应用启动。当前进程首次显式启动前展示兼容提示，可取消或继续启动。启动期间防止重复，区分左侧启动失败、右侧启动失败以及系统不支持；部分请求发出时说明已发送请求的一侧并可编辑或重试。系统接受启动请求后只报告“已发送启动请求”。两侧请求已发送后，读取系统双区状态和方向；双区形成后，方向与所选面积不符时通过已核对的 `IActivityTaskManager.SwapSplitPosition()` 调整一次，并等待系统动画、有界读回。方向调整不可用、被拒绝或未确认时分别反馈，仍保留两侧请求已发送的事实。方向读回不能确认两个外部应用的实际布局，由使用者检查；返回 SkyInfo 后保留原组合页与状态。

启动使用 Android `startActivity` 与 BYD `START_IVI_PRIMARY` / `START_IVI_SECOND` category，分屏动作独立于 ADB 授权。按比例将对应 category 分配给左右入口，先发送 `PRIMARY` 对应的小侧，800 ms 后复查并发送 `SECOND` 对应的大侧；`7/3` 先右后左，`3/7` 先左后右。先建立主容器可避免系统在主容器为空时恢复旧主应用，将已启动的另一侧任务移回主区。800 ms 只作发送节流，不证明主应用已完成布局；入口必须启用、导出且调用权限满足。左右同一组件会在发送前拒绝，同包的不同 Activity 可分别选择。选择 SkyInfo 自身的当前 MainActivity 时复用当前任务，并保留 BYD category。

候选 flags 为 `0x18033000`，组合 `NEW_TASK`、`MULTIPLE_TASK`、`REORDER_TO_FRONT`、`NO_ANIMATION`、`RETAIN_IN_RECENTS` 与 `LAUNCH_ADJACENT`；SkyInfo 当前 MainActivity 的任务复用使用 `0x00032000`（`REORDER_TO_FRONT`、`NO_ANIMATION`、`RETAIN_IN_RECENTS`）。`PRIMARY`、`SECOND` 表示系统容器，左右方向独立：当前已核对系统的方向值 `1` 为主区左侧，`2` 为主区右侧，分别对应 `3/7`、`7/3`；仅在显式启动时读取并调整方向；方向设置用于读回，调整通过系统窗口接口执行。标准 Android flags 不保证 OEM 左右映射及面积，`RETAIN_IN_RECENTS` 的通用作用受 `NEW_DOCUMENT` 条件限制。含义见 [Android Intent 文档](https://developer.android.com/reference/android/content/Intent)。系统不支持或安全校验拒绝时就地反馈，BYD 实际布局须逐设备和应用验收。Android 13 起，接收应用面向 API 33+ 时，外部显式 Intent 也可能受其 action/category 过滤规则约束；BYD category 被拒绝时按失败或部分请求反馈。规则见 [Android Intent 与过滤器](https://developer.android.com/guide/components/intents-filters)。

## 启动页面

设置 → 常规 → 运行增加“启动页面”，单选信息、悬浮窗、自定义分屏、连接、设置，默认信息。选中后即时保存，以“关闭”退出选择器；保存失败恢复原值并说明。

此偏好仅决定 SkyInfo 新的前台启动进入哪一页。普通返回前台保持当前页面；后台服务、开机恢复遵循原有生命周期。选择自定义分屏只打开组合页，外部应用仍由使用者点击组合的启动按钮。

## 适配与验收

参考设计为 1280×600dp，浅深结构一致，沿用 Fluorite 的中性背景、黄色主确认、48dp 触摸热区与 64dp 参数行。已保存组合行高80dp，面积图形左右使用 field/grid、外边界使用 edge；快速分屏的启动承担黄色主确认，新建组合为次操作。组合列表、选择结果及编辑参数独立滚动，标题、返回和主确认固定。宽屏左右预览与参数并列；窄屏按上下顺序重排，长名称与组件标识换行，软键盘下保留输入和退出操作。选择、取消、切换比例均不启动应用。

参考工程的启动路径与限制来自本地只读源码审阅，用于BYD启动适配分析。参考记录显示 BYD MagicWindow/AE 运行时兼容风险；实际布局须以目标设备逐应用验证。待验收覆盖进程重启恢复、卸载/更新失效、Activity 权限、首次启动兼容提示、部分启动失败、实际面积/左右位置、主题、触屏、字体缩放与启动页面持久化。本地行为与视觉覆盖及实车边界见[验证与兼容性](验证与兼容性.md)。
